# MICE第一版评分结果

## 结果范围与身份

2026-10-06，Lance bare-v2完整历史推理的Qwen单次评分，经人工补全31项裁判输出失败后的固定快照。31/31项明确判定，7通过、24不通过，无未评或仍待定。覆盖CM/CU各360会话，共720会话2160轮。

来源为`outputs/mice/full_bare_20261004_attention/`；自动证据在`outputs/scoring/full_qwen_once_pending_v3/`；本版结果在`outputs/scoring/mice_first_edition_human_v1/`。自动证据与人工评分库均原样保留，仅将3项IF、28项GA前缀的人工判定纳入本版，并重算累计GA。

自动协议mice-qwen-once-v3：Qwen3.6-27B，每项VLM一票，temperature=0.6、seed=42、context16384、max_tokens2048。IF保留Edit-R2分支与检测后处理；CC为GroundingDINO+DINOv3测量；GA使用原图至当前轮的完整前缀，累计GA取截至当前轮所有前缀分数的最小值。

本版属于项目替代裁判＋局部人工补评，不是官方榜单、全量人工评测或裁判准确率校准；不合成IF/CC/GA总分。

三轮累计通过数419→135→35。全部会话三轮累计GA通过率为35/720=4.8611%，等于第三轮累计GA，区别于跨三轮平均的27.2685%。按既定累计口径，首失败出现在第1/2/3轮的会话分别301/284/100，其余35会话全程通过。

原始前缀GA各轮独立询问，可能出现较早前缀0、较长前缀1的裁判差异。累计最小值消除了这类数值回升；“全程通过”指本版所有前缀判定均通过，不代表全量人工确认的视觉真值。

## 人工补评与自动基线比较

28项GA前缀人工判定7通过／21不通过，3项IF均不通过。37个累计GA空值已恢复，其中5个为1、32个为0。累计值按前缀依赖计算，7个直接前缀通过并不等于7个累计通过。原有合法自动分数全部不变。

| 指标 | 自动版均值（有效分母） | 第一版均值（有效分母） | 变化／百分点 |
| --- | ---: | ---: | ---: |
| IF | 41.8140%（2150） | 41.7557%（2153） | −0.0583 |
| CC | 67.7011%（1883） | 67.7011%（1883） | 0.0000 |
| 累计 GA | 27.5082%（2123） | 27.2685%（2160） | −0.2397 |
| 原始前缀 GA | 32.3640%（2132） | 32.2685%（2160） | −0.0955 |

变化来自补全分数与有效分母，不是重新推理后的能力变化。人工只处理输出失败，不能用7/31计算Qwen人机一致率。窗口展示过原回答，人工标签属于复核而非盲评真值。提示词调查发现的合法格式语义争议未在本版改判；后续校准另立版本。

## 结果解释与后续边界

当前轮IF与CC随轮次下降，保持所有既往前缀成功的会话比例下降更明显。CM三轮累计通过7/360，CU为28/360，当前CM历史约束任务表现更弱。CC均值尚高而IF／GA较低，表明内容相似度与编辑正确性可以分离；不能用高CC弥补不正确编辑。

这些现象与多轮约束维护和误差累积问题相符，但尚不能证明attention机制是原因。后续可按低IF类别、CM约束、CU指代和具体轮次做图像诊断，再提出attention分析／干预假设。
