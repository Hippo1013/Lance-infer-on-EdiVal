# Lance-infer-on-EdiVal

UMM 多轮图像编辑课题的预实验：在 EdiVal-Bench 上研究 Lance 推理时对历史轮次指令的注意力分布及其与编辑表现的关系。

## 实验阶段

1. 跑通 Lance 在 EdiVal-Bench 上的推理。
2. 保存推理中的 attention 分布，分析注意力熵、不同轮次及不同 token 的权重分布；具体指标待扩展。
3. 人为干预推理时的 attention 分布，观察对评测得分的影响。

## 当前状态

已初始化项目。当前处于第一阶段的环境准备，尚未接入 Lance、下载模型或数据集，也未运行推理或评测。

模型、数据集、生成图像及运行产物不纳入 Git 版本控制。后续按实际验证结果补充环境依赖、推理命令和评测步骤。
